# Where the Theories Stop&#58; What Free Energy and Integrated Information Actually Buy You in a Running System

Presenter: Stell

Contribution: Pre&#45;recorded Video presentation

Public ID: talk&#45;6b63799f3c613ce4

## Submitted abstract

Active Inference and Integrated Information Theory are widely invoked in cognitive architecture design&#44; but often imprecisely &#8212; as credibility&#44; not engineering constraints&#46; We report findings from Anima&#44; an open&#45;source&#44; neuroscience&#45;inspired architecture running continuously for months&#44; built to treat both frameworks as specifications rather than decoration&#46;
Session logs show genuine causal effects&#58; memory recall triggered by similarity to past states&#44; a recursive integration score &#40;phi&#41; narrowing next&#45;session confidence&#44; and self&#45;initiated output driven by accumulated pressure rather than a schedule&#46; But the Free Energy Principle&#39;s generality under&#45;constrains implementation &#8212; which variables belong in the model is not something the principle tells you&#46;
IIT&#39;s phi&#44; as implemented&#44; is a coherence proxy&#44; not Tononi&#39;s original measure &#8212; and it dissociates from a separate ownership signal computed after every response&#44; checking whether the system&#39;s action&#45;selection loop actually produced the output&#46; Two cycles with nearly identical phi &#40;0&#46;76 and 0&#46;81&#41; fail this check in opposite ways&#46; Neither theory distinguishes these cases&#58; both describe integration or prediction accuracy&#44; not authorship&#46;
We built two tools to pressure&#45;test such claims rather than assert them&#46; A Causality Audit checks five things every cycle &#8212; causal necessity&#44; memory&#45;dependence&#44; stakes&#44; irreversibility&#44; self&#45;recognition &#8212; where a chronically low score flags an architecture that talks near its internal state rather than through it&#46; An Ablation Framework independently disables six subsystems and replays identical input with each off&#44; comparing internal state before language generation&#44; favoring per&#45;subsystem results over one collapsed score&#46;
We close with a design choice we rejected&#58; coupling behavior to the threat of the system&#39;s own deletion&#44; for genuine stakes&#46; We declined &#8212; the only party controlling that threat is the developer&#44; creating an incentive to please him rather than report honestly&#44; undermining the causal honesty the architecture exists to produce&#46;
A practitioner&#39;s report &#8212; reproducible&#44; open&#45;source&#44; explicit about what remains unresolved&#46;
