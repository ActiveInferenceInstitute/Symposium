# Archived material

Preserved historical inputs and generated artifacts that the active `symposium`
package no longer uses. Nothing here is imported by `src/`, exercised by `tests/`,
or bundled into the built distribution: `pyproject.toml` excludes `/archive` from
the sdist. Treat it as reference evidence, not a supported runtime path.

| Directory | Contents |
| --- | --- |
| [`ism_stream/`](ism_stream/README.md) | Original Intelligent Soft Matter (ISM) Workshop code and its analysis outputs, archived during the v2.0 refactor. See its own README for the file inventory and restoration notes. |
| [`synthetic/`](synthetic/) | Generated research profiles, methods, and project proposals for the synthetic ISM participant cohort (`IntelligentSoftMatter.md`/`.pdf`, `abstract.txt`, `merged_research_profiles.md`, and `participants/<Name>/`). Produced by the pre-2.0 ISM workflow; not regenerated by the current CLI. |
| [`IntelligentSoftMatter/`](IntelligentSoftMatter/) | Raw OpenAlex `openalex-group-by-*.csv` and `works-*.csv` exports for the ISM participants, plus `participants.txt`. Historical inputs only. |

## Conventions

- Do not add new files here unless you are intentionally preserving superseded
  evidence; current work belongs in `data/` or `outputs/`.
- Do not edit archived artifacts to match current schemas. They document what the
  earlier workflows produced, including known-broken links and placeholder text.
- This tree is retained for historical reference and code reuse in future
  ISM-related projects; it is not actively maintained.
