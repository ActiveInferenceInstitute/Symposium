## Book and credits

The PDF and editable Word book cover the 6th Applied Active Inference Symposium,
November 12–13, 2026 (UTC). The approved public program supplies 57 contributions:
54 nonempty abstracts and three visibly pending abstracts. The book preserves the
submitted prose, uses 18 mm page margins, and includes a dated cover, generated
conceptual cover artwork and a generated illustration on physical page two.

The cover credits Active Inference Institute first, followed by all 52 exact
published presenter/group display labels. These are 53 credit entries, not a
verified count of distinct individuals. Composite presenter labels remain whole;
no person is inferred from a group string. Affiliations, ORCIDs and supplied
backgrounds appear only when an exact whole-label match exists in reviewed current
public sources: 9 eligible labels across 13 contributions, including 8 nonempty
affiliations, 4 ORCIDs and 4 backgrounds. Supplied self-reports are not verified
institutional or identity claims.

The book source remains the approved November 1 public program. Additional profile
information comes from the designated public 2026 participant view, rechecked
November 5, plus the explicitly reviewed public co-organizing-team affiliations
from the same program document. Historical participant rows are never a fallback
for missing current book profiles.

2026 cohort, with 15 empty substantive responses and 40 represented text corpora.

contributions, 52 distinct published presenter/group labels, and 3 missing
abstracts. A display-label count is not a distinct-person count. The new chart API
retains row order, missingness, actual method parameters and file digests; see the
[visualization guide](visualizations_2026.md).

The 55-record analysis cohort does not overwrite the historical 45-row program
snapshot. A name's absence from either source is not, by itself, evidence of
withdrawal. New intake and consent changes require their own source review and
explicit publication approval. Raw captures, source row identifiers, consent
ledgers, local build/preview receipts, credentials and paid-provider drafts are
excluded from the public release.
