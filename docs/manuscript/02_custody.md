# Artifact custody and rendering

The approved `program.json` and publication manifest retain byte-level bindings
for allowlisted artifacts. The public-tree check rejects unexpected files and
symlinks, validates digests and payload structure, and makes the tree eligible for
static publication. The site copies named downloads and approved pictures from the
verified tree. Core content is available as HTML even without JavaScript.

The existing independent native book adapter renders a reviewed project in the
Research Project Template. Its PDF and DOCX are inspected separately. An emitted
PDF is not by itself evidence of complete or legible layout. The book metadata and
artifact record bind the released edition. The program snapshot contract remains
independent of the separate published-proceedings metadata.
