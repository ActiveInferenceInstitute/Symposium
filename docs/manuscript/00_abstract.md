# Abstract

The Active Inference Symposium software publishes a static program from an approved
organizer snapshot. We describe how source mapping, allowlisted projection,
organizer decisions, artifact custody and a separately qualified rendering workflow
turn private intake into inspectable public records [@repository]. The released
Presenter Program provides a concrete edition for checking source and artifact
boundaries [@program2026]. This work documents publication controls and their limits.
It does not independently validate scientific claims in abstracts or participant
self-reports.
