# Review boundaries

Optional provider-based analysis can create draft profiles and summaries, with a
separate credential and consent boundary. Provider outputs do not enter the public
projection automatically. Identity, consent changes, disputed content and public
promotion need organizer decisions. Byte-level and schema checks cannot establish
that an abstract is factually true, that a third-party copy has been removed, or
that a browser presents content accessibly. Those questions require editorial or
native-viewer review beyond artifact verification.
