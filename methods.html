      Credentials & limits

      Credential setup and access guide

      This static site needs no API credentials and makes no model calls. Optional CLI workflows may require provider accounts, credentials and paid usage. OpenRouter and Perplexity refer to separate provider API credentials. InstituteOS documentation access is a separate, restricted documentation boundary; this public catalog grants no access.

      Review workflow documentation before running commands. Keep secrets in your local environment; never put keys or private source data in public bundles, catalogs or generated files.

      The catalog was reviewed on 2026-11-01. It is a curated snapshot, not a live inventory. Manual handoffs do not synchronize data or authorize publication. Organizers must approve public material separately.

      The discovery index contains methods, workflows and approved presentations. It excludes participant self-reports; the approved public directory remains in the program. Metadata does not independently verify research claims.
